# NIIT-PH-PASSIVE-OSINT-
## About This Project
This project documents a passive Open-Source Intelligence (OSINT) reconnaissance exercise carried out on **NIIT-PH.COM**. The main goal was to understand what information about a domain and its infrastructure can be discovered using publicly available sources, without attempting to gain unauthorized access to any system.

During the investigation, I looked at the domain's DNS information, IP address, WHOIS records, nameservers, registrar details, and hosting/network information. I also used OSINT tools such as **Maltego, theHarvester, and OSINT Framework** to collect and organize publicly available information.

## Purpose

This project was created as a practical learning exercise in OSINT and cybersecurity reconnaissance. It demonstrates how publicly available information can be gathered, verified, and presented in a structured way.

The findings in this repository should be treated as **reconnaissance observations**, not as proof of a vulnerability or compromise.

## Disclaimer

This assessment was conducted for authorized educational/security research purposes. No exploitation, unauthorized access, or attempts to compromise the target were performed.
